# AirTake Moblin — готовое приложение для Windows

**Эта версия использует готовый Moblin на iPhone. Собственное iOS-приложение не нужно.** Голос записывается с выбранного Fifine на ПК.

## Запуск

1. В Releases скачайте архив из релиза **AirTake Moblin Windows**.
2. Распакуйте весь ZIP и запустите `AirTake.exe`. Папка `tools` должна оставаться рядом. .NET, Python и OBS устанавливать не нужно.
3. Подключите iPhone и компьютер к одной локальной сети.
4. Выберите IP физического сетевого адаптера ПК, свой Fifine и папку записи.
5. Нажмите «Разрешить приём в брандмауэре Windows». Правило ограничено выбранным портом, FFmpeg и частной локальной сетью. Профиль Wi-Fi Windows должен быть частным. Брандмауэр не отключается.
6. В Moblin импортируйте QR / ссылку пресета. Резервный способ: Custom stream → SRT и SRT-адрес из AirTake; HEVC, 3840×2160, нужный FPS/битрейт.
7. Нажмите «Начать запись» в AirTake, затем Go Live в Moblin.
8. После Stop откройте папку записи.

## Возможности

- SRT с паролем, выбор адаптера/порта/буфера.
- QR-пресеты Moblin: 4K, 30/60/120 FPS, HEVC, 10–200 Мбит/с.
- Видеопоток копируется без перекодирования, масштабирования и искусственного изменения FPS.
- Fifine выбирается из реальных DirectShow-устройств. Звук сохраняется PCM 48 kHz в MKV; звук телефона не подменяет его.
- Ручной сдвиг микрофона ±10 секунд. Калибруйте хлопком: «+» задерживает звук, «−» сдвигает раньше.
- MKV с короткими кластерами; опциональный MP4 после Stop. Видео копируется, PCM перекодируется в AAC. Исходный MKV не удаляется.
- После разрыва создаётся новая часть. Есть журналы и session.json, контроль свободного места, остановка при остатке менее 512 МБ.
- Опциональный предпросмотр в отдельном окне. Он нагружает ПК и по умолчанию выключен.
- Настройки: `%LOCALAPPDATA%\AirTake\moblin-settings.json`. Файл и QR содержат пароль SRT: не публикуйте их.

## Честные ограничения

120 FPS в Moblin — экспериментальный режим. 4K120 в пресете не означает, что телефон действительно отдаёт этот режим: входящий формат показывается после подключения. Нагрев, длительность и реальный Wi-Fi проверяются на физических устройствах.

SRT повторяет пакеты только в пределах сетевого буфера. Пропавшие при длительном обрыве исходные кадры приложение восстановить не может. Нулевые потери и точная автоматическая синхронизация видео с Fifine **не заявлены**. Для важной съёмки резервная запись в Moblin включается отдельно.

При 120 Мбит/с видео занимает около 54 ГБ/час, плюс звук. MP4 требует дополнительного места, потому что MKV остаётся.

## Проверки и код

Актуальный модуль: `src/AirTake.Moblin/`. Сборка: `.github/workflows/moblin.yml`.

`dotnet publish src/AirTake.Moblin -c Release -r win-x64 --self-contained true`

CI запускает настоящий зашифрованный SRT-поток HEVC 3840×2160/120 между двумя процессами на Windows, проверяет файл ffprobe и запуск интерфейса. `tests.json` и `desktop.png` прикладываются к релизу. Это синтетический тест, не испытание реального iPhone/Wi-Fi/Fifine. Релиз помечен prerelease.

Другие модули репозитория, в том числе `ios/`, к этой Windows/Moblin-сборке не подключаются. Они сохранены без перезаписи параллельных изменений.
