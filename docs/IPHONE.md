# Установка AirTake Camera на iPhone

Windows-приложение и iOS-приложение — две обязательные части. Нельзя установить EXE на iPhone.

## Сборка IPA

Релиз содержит `AirTakeCamera-unsigned.ipa`. Это **сборка без подписи**, а не готовая установка по нажатию на файл. Её необходимо подписать вашей учётной записью Apple. AirTake не собирает Apple ID и пароли.

## С Windows — через Sideloadly

1. Скачайте Sideloadly с [официального сайта](https://sideloadly.io/).
2. Установите требуемые Sideloadly компоненты Apple по инструкции на его странице загрузки: веб-версии iTunes и iCloud, не версии Microsoft Store.
3. Подключите разблокированный iPhone к ПК кабелем для первой установки.
4. Подтвердите доверие к компьютеру на iPhone.
5. Откройте Sideloadly.
6. Выберите подключённый iPhone.
7. Перетащите `AirTakeCamera-unsigned.ipa` в окно Sideloadly.
8. Укажите свой Apple ID непосредственно в Sideloadly.
9. Нажмите Start.
10. Подтвердите вход Apple, если программа запросит авторизацию.
11. Включите Developer Mode на iPhone, если iOS потребует его для запуска.
12. Откройте AirTake Camera на iPhone.

Не передавайте Apple ID, пароль, коды подтверждения или сертификаты в чат. Sideloadly — отдельный сторонний инструмент; способ авторизации и установки контролируется им, а не AirTake.

По документации Sideloadly подпись бесплатного Apple ID действует 7 дней; предусмотрено автоматическое обновление подписи. После первого подключения возможна переустановка по Wi-Fi. Это отдельная процедура от беспроводной видеозаписи AirTake. Проверка конкретной IPA через Sideloadly на реальном устройстве ещё не выполнена.

Источники: [Sideloadly — установка и FAQ](https://sideloadly.io/), [Apple — Developer Mode](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device). Проверено 19 сентября 2026 года.

## Через Xcode на Mac

1. Установите Xcode.
2. Установите XcodeGen командой `brew install xcodegen`.
3. В каталоге `ios` выполните `xcodegen generate`.
4. Откройте `AirTakeCamera.xcodeproj`.
5. В Signing & Capabilities выберите свою Team.
6. При необходимости задайте уникальный Bundle Identifier.
7. Выберите подключённый iPhone 16 Pro.
8. Нажмите Run.
9. Подтвердите доверие/Developer Mode на iPhone, если этого требует iOS.

После установки кабель для записи не нужен. Нет ни удалённой подписи, ни подготовленного TestFlight, ни доступных автору сертификатов пользователя.

## Первое подключение

1. Откройте AirTake.exe на ПК.
2. Сохраните правильный LAN-адрес в настройках.
3. Разрешите частную сеть в брандмауэре через кнопку приложения.
4. Подключите iPhone к той же локальной сети.
5. Откройте AirTake Camera.
6. Разрешите доступ к камере.
7. Разрешите доступ к локальной сети.
8. Нажмите «Сканировать QR с ПК».
9. Нажмите «Начать запись» в Windows.

Камера — только основная задняя 1×; интерфейс горизонтальный. Микрофон телефона не запрашивается и не записывается. Fifine выбирается в Windows. Блокировки фокуса/экспозиции/баланса белого применяются к работающей камере.

При смене LAN-адреса, порта, токена или сертификата повторно отсканируйте QR. QR содержит секрет: не публикуйте его.
