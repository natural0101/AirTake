# Первый запуск

## Windows

1. Скачайте AirTake-Windows-x64.zip из Releases.
2. Распакуйте архив целиком, включая `tools`.
3. Запустите `AirTake.exe`.
4. Во вкладке «Звук» выберите свой **Fifine**.
5. Во вкладке «Диск» выберите папку на нужном диске.
6. Во вкладке «Подключение» выберите локальный IPv4-адрес сетевого адаптера, через который доступен iPhone.
7. Во вкладке «Камера» задайте 4K, 120 fps и целевой битрейт.
8. Нажмите «Сохранить / перезапустить».
9. Разрешите входящие подключения кнопкой «Разрешить в брандмауэре», если их блокирует Windows.

Приложение не подписано коммерческим Windows-сертификатом. Перед запуском проверьте источник загрузки и контрольные суммы. Не отключайте антивирус или брандмауэр целиком. Создаваемое правило ограничено приложением, портом, выбранным IP, частным профилем и локальной подсетью. Права администратора нужны только для этой кнопки.

## iPhone

Нужен AirTake Camera: Safari, стандартная «Камера» и сторонний веб-камерный клиент не говорят по протоколу AirTake.

IPA в релизе — **unsigned**, без сертификата и provisioning profile. Сам по себе он не устанавливается на iPhone. Подпишите его своим Apple ID через совместимое локальное средство установки либо соберите приложение в Xcode с вашей командой подписи. Пароли Apple вводятся только в выбранном вами средстве подписи, не в AirTake и не в чат.

### Установка через Xcode на Mac

1. Установите Xcode.
2. Установите XcodeGen командой `brew install xcodegen`.
3. Скачайте исходники репозитория.
4. Выполните `cd ios && xcodegen generate` в папке проекта.
5. Откройте `AirTakeCamera.xcodeproj`.
6. Выберите свой Team в Signing & Capabilities.
7. Подключите iPhone к Mac для первоначальной установки.
8. Выберите iPhone как устройство запуска.
9. Нажмите Run.
10. Разрешите Developer Mode на iPhone, когда это потребуется системой.

После установки съёмка и передача работают по Wi-Fi; кабель к компьютеру для записи не требуется.

## Сопряжение и запись

1. Подключите iPhone и ПК к одной локальной сети.
2. Откройте AirTake Camera.
3. Разрешите доступ к камере и локальной сети.
4. Нажмите «Сканировать QR» в AirTake Camera.
5. Отсканируйте код во вкладке «Подключение» на ПК.
6. Нажмите «Тест Wi-Fi» на iPhone для измерения пути iPhone → ПК.
7. Нажмите REC на одном из устройств.
8. Нажмите «Остановить» для завершения дубля.
9. Дождитесь сообщения «MP4 сохранён на ПК» перед закрытием приложений.

Готовый файл: `<папка записи>/<ID дубля>/AirTake.mp4`. Журнал дубля: `take.json`. Лог сборки: `mux.log`. Общий лог Windows: `%LOCALAPPDATA%\AirTake\airtake.log`.

## Настройки

- Настройки в Windows применяются кнопкой «Сохранить / перезапустить» и блокируются во время дубля.
- «Буфер iPhone» ограничивает неподтверждённые видеофрагменты. При переполнении запись останавливается, очередь сохраняется.
- «Предпросмотр» отправляет дополнительную JPEG-картинку раз в секунду; исходное видео остаётся HEVC в выбранном разрешении.
- Положительный «Сдвиг звука» задерживает микрофон относительно видео. Проверяйте хлопком: автоматическая синхронизация не устраняет неизвестную задержку драйвера.
- «Сохранять исходные фрагменты и WAV» сохраняет исходники после успешного MP4. При ошибке они остаются независимо от настройки.
- Основная камера используется только 1×; 4K/120 не подменяется 60 fps с дубликатами.

## Ошибки

**Не подключается:** проверьте правильный сетевой адаптер, частный профиль Windows, локальную сеть iPhone, VPN и изоляцию клиентов/гостевую сеть роутера. Не открывайте порт в интернет.

**Формат не поддерживается:** приложение покажет фактическую ошибку камеры/аппаратного энкодера. Выберите другой поддерживаемый режим; заявка «120» не является доказательством 120 настоящих кадров.

**Wi-Fi пропал:** телефон продолжает сохранять очередь в пределах лимита и повторяет отправку. Не удаляйте приложение и его данные. После восстановления связи фрагменты досылаются.

**Высокий нагрев:** наблюдайте реальные FPS и пропуски. При критическом состоянии приложение останавливается. Продолжительность устойчивых 4K/120 определяется физическим тестом, не надписью в настройках.

**MP4 не собрался:** проверьте свободное место и `mux.log`, исправьте причину и повторите передачу на iPhone. В Windows также есть «Восстановить незавершённую запись» с явным выбором восстановления видео без звука или с сохранённым WAV.

**Подпись iPhone истекла:** переустановите/обновите подпись своим средством установки. Не удаляйте приложение с неподтверждёнными фрагментами без предварительного сохранения данных.
